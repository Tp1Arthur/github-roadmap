# Módulo 9 — GitHub Pages

## Conceitos

**GitHub Pages**
- Serviço gratuito do GitHub que publica arquivos HTML/CSS/JS de um repositório como um site acessível publicamente.
- URL no padrão: `https://usuario.github.io/nome-do-repositorio/`

**Por que é valioso pro portfólio**
- Transforma código em algo que qualquer pessoa pode ver e "usar", sem precisar baixar ou entender de programação.

**Estrutura básica de HTML**
- `<!DOCTYPE html>` — avisa ao navegador que é um documento HTML
- `<html>` — envolve todo o conteúdo
- `<head>` — informações que não aparecem visualmente
- `<body>` — tudo que aparece na tela

**Ativando o GitHub Pages**
- Feito em **Settings → Pages**, escolhendo a branch e a pasta de origem.
- Leva alguns minutos para o site ficar disponível.

## Prática realizada
Estrutura HTML completa no `index.html`, GitHub Pages ativado e site publicado com sucesso.

# Módulo 13 — GitHub Projects

## Conceitos

**GitHub Projects (Kanban)**
- Um quadro visual dividido em colunas de status (To Do, In Progress, Done), usado para organizar e acompanhar tarefas.
- Ferramenta comum em times ágeis (Scrum, Kanban).

**Conexão com Issues**
- As Issues do repositório podem ser vinculadas diretamente ao quadro.
- Cada card corresponde a uma Issue real — mover o card reflete o status da Issue.

**Fluxo de colunas**
- O template usado trouxe: Backlog → Ready → In progress → In review → Done.

## Prática realizada
Criação de um Project chamado "Roadmap Github - Organização", com as 5 Issues existentes vinculadas ao quadro, na coluna Backlog.

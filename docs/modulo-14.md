# Módulo 14 — Releases

## Conceitos

**Release**
- Um "marco" no histórico do repositório, marcando um ponto específico como uma versão oficial e pronta.

**Versionamento Semântico (SemVer)**
- Formato: `vMAIOR.MENOR.PATCH` (ex: `v1.0.0`)
- **MAIOR** — mudanças que quebram compatibilidade com versões anteriores
- **MENOR** — novas funcionalidades, mantendo compatibilidade
- **PATCH** — correções pequenas, sem adicionar funcionalidade nova

**Criando uma Release no GitHub**
- Feito na aba **Releases**, criando uma nova tag, título, e descrição do conteúdo daquela versão.

## Prática realizada
Criação da Release `v1.0.0`, marcando a primeira versão "pronta e apresentável" do projeto.

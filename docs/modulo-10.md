# Módulo 10 — Issues

## Conceitos

**Issue**
- Um "post-it" dentro do repositório, usado para registrar tarefas pendentes: bugs, funcionalidades novas, melhorias.
- Centraliza o que precisa ser feito em um único lugar visível para todos com acesso ao repositório.
- Funciona também como registro histórico de decisões e planejamento.

**Boas práticas de título**
- Issues funcionam melhor com títulos específicos e acionáveis, em vez de objetivos genéricos.

**Fechando uma Issue**
- Manualmente pelo botão **Close issue**.
- Automaticamente: mencionar `closes #numero-da-issue` na mensagem de um commit.

## Prática realizada
Criação de 5 Issues no repositório, documentando melhorias planejadas para o README e index.html.

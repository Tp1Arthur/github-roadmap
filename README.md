## 📖 Sobre

Este repositório documenta 15 módulos de estudo prático de Git e GitHub, guiados por IA, saindo de *"sei dar push"* para *"consigo trabalhar em um fluxo profissional real"*. Cada módulo gerou algo tangível: commits, branches, uma página publicada, um workflow de CI.

## 🤖 Como aprendi

Estudei esse roadmap usando o **Claude (Anthropic)** como instrutor interativo, seguindo uma metodologia deliberada:

- 🎯 **Um módulo por vez** — nunca avançava sem confirmar o entendimento
- ❓ **Perguntas antes de respostas** — era guiado a raciocinar antes de receber a solução pronta
- 💻 **Prática real no terminal** — nada de exemplos hipotéticos
- 📝 **Resumo escrito ao final de cada módulo** — consolidando conceitos antes de seguir

<details>
<summary><strong>Ver o prompt usado</strong></summary>
<br>

> "Vá me ensinando o roadmap módulo por módulo. Não me dê a solução completa de uma vez — me guie com perguntas, deixe eu tentar raciocinar antes de responder, e só corrija quando eu errar. Ao final de cada módulo, escreva um resumo dos conceitos e comandos aprendidos antes de avançarmos para o próximo."

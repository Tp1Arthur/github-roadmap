# 🗺️ Roadmap GitHub Fundamentals

Este documento detalha cada módulo da minha jornada de aprendizado prático de Git e GitHub. Também serve como guia caso você queira seguir o mesmo caminho.

## Sobre este roadmap

Cada módulo combina teoria curta + prática imediata. Ao final de cada um, algo real fica registrado no repositório: um commit, uma branch, uma página publicada.

**Pré-requisitos:** Git instalado, conta no GitHub, terminal Linux/Mac/WSL.
**Duração sugerida:** 3 a 4 semanas, ~1 hora por dia.

## Como usar este repositório como guia

1. Siga os módulos na ordem — cada um usa conceitos do anterior como base.
2. Pratique no seu próprio repositório, não só leia.
3. Explore o histórico de commits (`git log --oneline`) para ver exemplos reais de cada tipo de commit.
